치안 통계 점수·5등급 — Git 업로드용 필수 파일

구성: 핵심 9개 파일 + validation 검증 기록 7개 + tests 회귀 테스트 1개, 총 17개 파일.
이 폴더의 내용을 팀 저장소 services/safety_scoring/에 넣으면 됩니다.

확정 기준
순위 기반 상대점수, 범죄 80%·방범 CCTV 10%·지구대·파출소 10%.
1등급 80~100점 / 2등급 60점 이상 80점 미만 / 3등급 40점 이상 60점 미만 /
4등급 20점 이상 40점 미만 / 5등급 0점 이상 20점 미만.
등급 부여 전에 반올림하지 않으며 결측값은 0으로 바꾸지 않습니다.
Python 파일은 정해진 통계 산식으로 점수와 등급을 계산합니다. AI 학습·범죄 예측은 수행하지 않습니다.

핵심 파일 9개
1. results/safety_scores.json : 427행정동 최종 점수·등급. 3번 및 백엔드 전달용.
2. src/safety_scoring.py : 인구 대비 지표, 평균순위 점수, 80·10·10 가중합.
3. src/safety_grading.py : 점수를 고정 구간 5등급으로 변환.
4. src/evaluation_contract.py : 행정동 코드·이름·점수·결측 규칙 검증.
5. src/backend_contract.py : 백엔드 JSON 형식 변환과 검증.
6. src/build_safety.py : 입력부터 결과 JSON까지 재계산·저장·대조.
7. data/safety_scoring_input.json : 범죄·인구·CCTV·경찰시설·관할 연결 입력.
8. data/서울_지역_기준.csv : 1번 담당자 기준 427행정동 코드·이름·자치구.
9. README.txt : 계산 기준, 구성, 실행·연결 방법과 출처.

validation 폴더
01_행정동_등급분포.csv : 등급별 행정동 수.
02_427행정동_점수등급.csv : 모든 행정동 결과 목록.
03_1등급_5등급_산출근거.csv : 해당 등급 지역의 원값과 점수 기여.
04_결과재현_실행로그.txt : 이번 최소 구성에서 재계산·대조한 실행 기록.
05_테스트_실행로그.txt : 이 패키지의 tests/test_safety_contract.py를 직접 실행한 14개 테스트 기록.
06_패키지검증.json : 6자리 코드 연결·점수 보존·재현·테스트 검증 결과.
07_파일목록과해시.json : 자기 자신을 제외한 16개 파일의 목록·크기·SHA-256.

실행 (Python 3.10 이상, 외부 패키지 설치 불필요)
현재 입력과 저장된 결과가 같은지 확인:
  python -B src/build_safety.py --verify
입력 통계로 결과를 다시 생성:
  python -B src/build_safety.py
현재 계산기는 2025년 범죄·인구·관할 기준과 427행정동 기준표를 검증합니다.
다른 연도의 평가로 갱신할 때는 입력만 바꾸지 말고 코드의 기간 검증과 설명도 함께 검토하세요.

백엔드 사용
items[].region.region_code : 프로젝트 기준 6자리 행정동 코드 문자열.
items[].region.sigungu_code : 5자리 자치구 코드 문자열.
region_code는 6자리입니다. 이전 항목명 region_short_code와 parent_region_code는 전달하지 않습니다. 10자리 행정동 코드는 이 전달 형식에서 받지 않습니다.
items[].scores.safety : 추천 가중합에 사용할 0~100점.
items[].metadata.safety.grade / grade_label : 화면 표시용 1~5등급. 1등급이 최고.
metadata.safety.grade_rules : 등급 구간.
다른 평가 영역의 null을 다른 담당자의 실제 점수에 덮어쓰지 마세요.
백엔드는 metadata를 보존하고 프론트는 grade를 읽어야 합니다.

자료 출처와 기간
범죄: 보완 검증한 2025년 5대범죄 관할권역 입력.
공식 범죄 자료 목록: https://www.data.go.kr/data/15054738/fileData.do
인구: 2025년 12개월 월말 주민등록인구 평균.
CCTV: 1번 제공 CCTV_202610140957.csv 기반, 기존 입력의 기준일 2026-06-30.
경찰시설: 1번 제공 서울 경찰서 수_202610141000.csv 및 보완 시설 목록, 2025-12-31.
행정동 기준: 1번 제공 서울_지역 엑셀용.csv의 427개 행정동.
관할 연결 기준: 2025-12-31.

해석
범죄·경찰시설은 25개 관할권역, CCTV는 25개 자치구 기준입니다.
이를 조합한 26개 평가값을 427행정동에 연결합니다. 동별 실측 범죄 발생률이나 피해 확률이 아닙니다.
가중치는 확정한 설계 기준이며 학습한 인과효과가 아닙니다.
등급은 고정 점수 구간이므로 등급마다 같은 수의 동이 배분되지 않습니다.
원본의 calculated_draft 상태, 관할 검토 메모, CCTV 기준일 해석 관련 quality_flags는 유지합니다.
1등급 49동, 2등급 98동, 3등급 80동, 4등급 167동, 5등급 33동.

보관 안내
이전 10자리 버전 및 과거 검증 기록은 D드라이브의 지역코드_6자리통일_2026-10-21/before/safety에 보관했습니다.
현재 회귀 테스트 코드는 tests/test_safety_contract.py에 포함합니다.
이 최소 묶음만으로 현재 점수와 등급을 재계산할 수 있습니다.

지역코드 변경 (2026-10-21)
main의 data/processed/서울_지역 엑셀용.csv에 있는 region_short_code(6자리) 값을 명시적으로 조회했습니다. 이 원천 열의 값은 그대로 두고 전달 항목명만 region_code로 사용합니다.
코드를 잘라서 추정하지 않습니다. 427개 행정동·이름·소속 자치구를 그대로 유지합니다.
예: 미아동 {"region_code": "305535", "sigungu_code": "11305"}.
입력·산출 CSV·최종 JSON은 동일한 6자리/5자리 규칙이며 경제 영역도 같은 규칙으로 연결할 예정입니다.
구현 코드가 이전 필드 이름을 검사하는 것은 잘못된 입력을 거부하기 위한 것입니다.

연결 시 확인할 사항
이 변경은 치안 담당 폴더에만 적용했습니다. main의 지역 원본이나 팀원의 백엔드·프론트 코드는 수정하지 않았습니다.
현재 main의 API·지도 연결이 10자리 region_code 또는 parent_region_code를 요구한다면
담당자가 region_code(6자리)와 sigungu_code(5자리)를 읽도록 맞춘 후 연결해야 합니다.
이 JSON을 기존 10자리 조회 코드에 곧바로 덮어쓰면 연결되지 않을 수 있습니다.
관할권역의 POL2025_... region_id/jurisdiction_id는 행정동 코드가 아니므로 유지합니다.
