# 치안 통계 평가

427개 프로젝트 행정동에 치안 점수와 5등급을 연결하는 실행 패키지입니다. 별도의 AI 학습이나 미래 범죄 예측은 하지 않습니다. Python 3.10 이상에서 표준 라이브러리만 사용합니다.

## 사용

이 폴더에서 실행합니다. 입력·결과 경로는 코드 위치를 기준으로 찾아가므로 D드라이브나 특정 사용자 경로가 필요하지 않습니다.

```sh
python -B src/build_safety.py --verify
python -B -m unittest discover -s tests -v
```

현재 입력을 다시 계산해 저장하려면 `python -B src/build_safety.py`를 실행합니다. 다른 자료기간을 적용할 때는 입력만 교체하지 말고 지역·기간·관할 연결과 코드의 고정 기간 검증도 함께 갱신합니다.

## 전달할 JSON

`results/safety_scores.json`을 읽습니다.

| 항목 | 사용 방법 |
|---|---|
| `items[].region.region_code` | 6자리 문자열. 프로젝트 행정동 식별자 |
| `items[].region.sigungu_code` | 5자리 문자열. 자치구 식별자 |
| `items[].region.name_ko` | 행정동 이름 |
| `items[].scores.safety` | 추천 종합점수에 사용할 0~100 치안 점수 |
| `items[].metadata.safety.grade` | 1~5등급. 1등급이 가장 높음 |
| `items[].metadata.safety.components` | 범죄·CCTV·경찰시설의 실제 수치와 점수 기여 |
| `metadata.safety.source_periods` | 자료별 실제 기준기간 |

다른 영역 점수는 `null`입니다. 이미 전달받은 다른 영역의 점수에 이 `null`을 덮어쓰지 않습니다. 메타데이터를 보존해야 근거와 자료기간을 설명할 수 있습니다. 기존 `region_short_code`를 `region_code`로 이름만 바꿨으며, 6자리 값은 그대로입니다. 10자리 코드·`parent_region_code`를 요구하는 소비 코드는 이 계약으로 맞춰야 합니다.

## 계산

1. 5대 범죄 발생건수(살인·강도·성범죄·절도·폭력), 방범 CCTV 수, 지구대·파출소 수를 각각 주민등록인구 1만 명당 수치로 만듭니다. 인구는 2025년 12개월 월말인구의 평균입니다.
2. 각 지표의 25개 비교지역에서 평균순위를 구합니다. 동점은 같은 점수입니다. 범죄는 적을수록, 시설은 많을수록 높은 점수입니다.
3. 치안 점수 = 범죄 점수 × 0.80 + CCTV 점수 × 0.10 + 경찰시설 점수 × 0.10.
4. 반올림하지 않은 점수로 80 이상 1등급, 60 이상 2등급, 40 이상 3등급, 20 이상 4등급, 20 미만 5등급을 부여합니다. 결측은 0점이 아닙니다.

범죄와 경찰시설은 **25개 통합 경찰 관할권역**, CCTV는 **25개 자치구**에서 비교합니다. 권역과 자치구의 조합인 26개 평가값을 427개 행정동에 연결합니다. 행정동 427개를 서로 독립인 범죄 관측으로 간주하지 않습니다.

## 실제 자료기간과 해석

| 자료 | 입력에 기록된 기준 | 공간 단위 |
|---|---|---|
| 5대 범죄 | 2025년 연간 | 경찰서 자료를 통합한 관할권역 |
| 주민등록인구 | 2025년 1~12월 월말인구 평균 | 관할권역·자치구 |
| 방범 CCTV | 2026-06-30 | 자치구 |
| 지구대·파출소 | 2025-12-31 | 관할권역 |
| 관할 연결표 | 2025-12-31 적용 | 행정동 ↔ 관할권역 |

범죄 공식 자료 목록: https://www.data.go.kr/data/15054738/fileData.do

427개 지역 기준은 팀의 `서울_지역 엑셀용.csv`에서 가져왔습니다. 원천의 `region_short_code` 6자리 값을 명시적으로 연결했으며, 10자리 값을 잘라서 만들지 않았습니다.

## 서비스에서 표시할 의미와 남은 자료 한계

권장 화면 표기는 **“관할지역 기반 치안 참고점수”**입니다. 동 자체에서 실측한 범죄율, 개인 피해 확률, 현재월 예측값이라는 뜻으로 표시하지 않습니다. CCTV·경찰시설이 많을수록 범죄가 감소한다는 인과효과를 학습한 값도 아닙니다.

확정한 80·10·10 계산식과 점수·등급은 그대로 유지했고, 재계산·코드 연결·경계값·결측 처리를 검증했습니다. 다만 기존 `calculated_draft`와 다음 원천 검토 표시는 삭제하지 않았습니다. 계산의 재현성 검증과 원천자료의 완전성은 구분해야 합니다.

- 50개 동의 일부 관할 연결은 공식 법정동 근거를 2025년에 적용한 추론이며, 2025년 동별 전체 관할대장을 직접 확인한 것은 아닙니다.
- 범죄 항목의 상세 성범죄 정의 일관성 검토 표시가 남아 있습니다.
- CCTV 원문의 날짜 표기에 오류가 있어 기준일은 파일명·수신 자료에 근거했습니다.
- 서로 다른 자료기간을 혼합했고, 경찰 관할은 연중 전체 변동을 재검증한 연결이 아닙니다.

따라서 이 패키지는 명시한 범위의 통계 참고점수를 서비스에 연결할 수 있는 실행 묶음입니다. 미해결 원천 검토 표시를 숨기거나 “동별 현재 안전을 확정했다”고 설명해서는 안 됩니다.

## 필수 파일

- `src/` 5개: 순위 계산, 등급 부여, 지역·JSON 검증, 재생성 실행 코드.
- `data/` 2개: 입력 통계 JSON과 427개 지역 기준 CSV.
- `results/safety_scores.json`: 서비스 전달 결과.
- `tests/test_safety_contract.py`: 회귀·오류 처리·입출력 계약 검증.
- `validation/02_427행정동_점수등급.csv`: 결과와 행 단위로 대조할 표.
- `validation/release_validation.json`: 이번 검사 결과와 파일 해시.
- `README.md`: 실행·계산·연결·자료 한계 설명.

현재 등급 분포는 1등급 49동, 2등급 98동, 3등급 80동, 4등급 167동, 5등급 33동입니다. 등급별 동 수를 균등하게 나누는 방식이 아닙니다.
