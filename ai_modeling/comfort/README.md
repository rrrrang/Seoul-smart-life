# 생활쾌적도 점수 전달 자료

이 폴더는 생활쾌적도 평가 결과를 백엔드 및 추천모델 담당자에게 전달합니다. 평가 단위는 **서울시 25개 자치구**입니다. 행정동 코드나 행정동명은 이 모델의 입력·출력에 포함하지 않으며, 자치구 점수를 행정동별 점수로 복제해서 해석하지 않습니다.

## 폴더 경로와 역할

공동 Git 저장소에서 이 패키지의 경로는 `ai_modeling/comfort/`입니다. `ai_modeling/` 아래의 개별 평가모델 패키지 중 하나로, 생활쾌적도 점수를 산출하고 그 결과를 백엔드·추천모델에 전달합니다. 이 폴더는 추천 결과를 직접 만들거나 백엔드 API를 구현하는 위치가 아닙니다.

| 경로 | 역할 |
|---|---|
| `ai_modeling/comfort/README.md` | 패키지 목적, 데이터 계약, 점수 해석과 연동 조건 안내 |
| `ai_modeling/comfort/src/` | 생활쾌적도 점수 산출 코드 |
| `ai_modeling/comfort/results/` | 백엔드·추천모델에 전달하는 JSON 및 분석용 CSV 결과 |

개발 작업 원본은 별도 프로젝트 경로인 `C:\Users\human\Desktop\living_comfort\comfort_score.py`에 있습니다. 저장소의 `ai_modeling/comfort/src/comfort_score.py`는 공동 저장소에 전달하는 사본입니다. 실행 결과는 작업 원본 프로젝트의 `reports/comfort_score/`에 생성되며, Git 전달본은 필요한 결과를 `ai_modeling/comfort/results/`에 복사해 관리합니다.

## 전달 파일

| 파일 | 설명 |
|---|---|
| `results/comfort_scores.json` | 공통 계약 형식의 최신 평가월 자치구별 점수. 현재 기준월은 `2026-09`이며 25개 자치구 레코드가 있습니다. |
| `results/monthly_scores.csv` | 자치구·월별 상세 점수와 지표별 점수·원자료 값. 현재 2024-01부터 2026-09까지의 결과입니다. |
| `results/region_ranking_period_relative.csv` | 전체 자료기간 평균을 기준으로 산출한 자치구 상대순위 및 순위 점수입니다. 월별 점수와 기준이 다릅니다. |
| `src/comfort_score.py` | 점수 산출 코드입니다. 현재 전달된 결과를 재생성하는 데 필요한 원본·정제 입력자료는 이 폴더에 포함되어 있지 않습니다. |

## JSON 계약

`results/comfort_scores.json`은 JSON 배열이며, 각 항목은 자치구 하나를 나타냅니다.

| 필드 | 형식 및 의미 |
|---|---|
| `행정구코드` | 5자리 자치구 코드 문자열. 선행 0이 보존되도록 문자열로 처리합니다. |
| `행정구명` | 자치구명 |
| `평가분야` | `생활쾌적도` |
| `평가기준월` | 점수 기준월(`YYYY-MM`). 현재 제공값은 `2026-09`입니다. |
| `사용자료_기준기간` | 월별 통합자료의 기간. 현재 제공값은 `2024-01~2026-09`입니다. |
| `점수` | 0~100 범위의 최신 기준월 쾌적도 상대점수 |
| `계산상태` | 점수 계산 가능 시 `완료`, 계산 불가 시 `불가` |
| `계산불가사유` | 계산 가능 시 빈 배열, 불가 시 사유 문자열 배열 |

코드 비교·병합은 `행정구코드` 문자열을 사용합니다. 행정동 코드·이름은 제공하지 않습니다. `계산상태: 완료`는 점수를 산출했다는 뜻이며, 해당 점수가 정책적으로 승인되었거나 자치구의 절대적인 쾌적도를 보증한다는 뜻은 아닙니다.

## 점수 해석

현재 활성 설정은 `design_sheet1`, 점수 방식은 `relative`입니다. 월별로 자치구 간 각 지표 순위를 0~100으로 바꾼 뒤 아래 가중치로 합산합니다.

| 지표 | 정규화 가중치 |
|---|---:|
| 기온 | 26.2% |
| PM2.5 | 28.7% |
| PM10 | 17.0% |
| 소음 | 28.0% |
| 오존 | 제외(0%) |

따라서 `comfort_scores.json` 점수는 해당 월의 25개 자치구 안에서의 **상대 비교 점수**입니다. 서로 다른 월의 점수를 절대적인 변화량처럼 직접 비교하지 마세요. 전체기간 평균 상대순위를 확인할 때는 `region_ranking_period_relative.csv`의 `period_rel_score`를 사용합니다. 이 값은 최신월 JSON의 `점수`와 산출 기준이 다릅니다.

## 추천모델 연동 시 유의사항

- 현재 점수 스냅샷은 2026년 9월 기준입니다. 추천 기준월이 2026년 10월이면 기준월 차이를 메타데이터에 유지하고, 9월 자료를 10월 실측값으로 표시하지 마세요.
- 이 JSON은 자치구 단위 결과 계약입니다. 추천모델에서 사용하는 입력 계약에 맞춘 변환 또는 어댑터가 필요할 수 있습니다.
- 여러 평가분야를 합산할 때는 모든 분야의 추천 단위를 자치구로 통일해야 합니다. 행정동 단위 점수를 단순 복제해 자치구 결과인 것처럼 취급하지 마세요.
- 상대점수라는 점과 사용자료 기준기간을 API 응답·화면의 설명에도 보존하세요.

## 재현에 필요한 입력

점수 산출 코드는 `air_quality`, `noise`, `temperature`의 정제 월별 CSV를 사용합니다. 대기자료 보정 파일이 있으면 코드가 이를 우선 사용합니다. 원본 또는 정제 입력파일과 정확한 데이터 제공처·버전은 현재 이 전달 폴더에 포함되어 있지 않으므로, 결과 재현이 필요한 경우 입력자료와 설정·자료 출처 문서를 별도로 패키징해야 합니다.
