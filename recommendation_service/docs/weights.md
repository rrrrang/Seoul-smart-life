# 확정한 가중치 정책

사용자와 논의해 **각 슬라이더를 독립적으로 조절하고 실제 비중을 따로 표시**하는 방식을 유지했다. 프론트 슬라이더 범위는 0~100으로 두며 서버 계산기는 음수가 아닌 유한 가중치를 합계로 정규화한다. 서버 API에서 0~100 범위를 강제할지는 프론트 계약에 맞춰 추가할 수 있다. 추천 함수 자체는 100보다 큰 양수도 비율로 처리한다.

```text
실제 비중 = 해당 슬라이더 값 / 전체 슬라이더 합계
종합점수 = Σ(영역별 100점 점수 × 실제 비중)
```

| 설정 | 실제 비중/결과 |
|---|---|
| 다섯 영역 모두 20 | 각각 20% |
| 다섯 영역 모두 100 | 각각 20%, 위와 같은 순위 |
| 다섯 영역 모두 10 | 각각 20%, 위와 같은 순위 |
| 치안100, 나머지25씩 | 치안50%, 나머지 각12.5% |
| 치안100, 나머지0 | 치안 점수순, 동점은 region_code 오름차순 |
| 모두0 | 계산하지 않고 최소 한 항목을 올리도록 안내 |

슬라이더100은 지역 점수100·최소점수100·1등급 필터를 의미하지 않는다. 높은 가중치는 다른 항목이 같을 때 그 영역의 점수가 높은 지역을 유리하게 한다. 원래 영역 점수·원래 등급은 바뀌지 않는다. 전체 슬라이더에 같은 배수를 적용하면 결과가 같다.

## 화면 표시

- 각 막대는 recommendation.items[].category_scores의 원점수를 **100점 만점**으로 표시한다.
- 종합은 personalized_score_100이다. 단순합이 아니라 가중평균이다.
- 실제 비중은 recommendation.normalized_weights 값 ×100. 예:0.2→20%.
- normalized_weights 값은 계산용 정밀도를 유지하고 화면만 반올림한다. 반올림 합계가 99.9%일 수 있으며 계산에는 반올림 값을 다시 보내지 않는다.
- domain_points_20, selected_total_points, selected_max_points, five_domain_total_points는 기존 계약 호환용 환산값이다. 화면의 영역 막대와 종합점수에 사용하지 않는다. five_domain_total_points도 가중 개인화 점수와 다른 값이다.
- 결측은 0점으로 바꾸지 않는다. 요청한 영역 점수가 없는 지역은 제외한다.

## 지도 색

치안 등급 지도는 슬라이더와 관계없이 원래 치안 등급을 표시한다. 사용자 맞춤 종합점수 지도는 바뀐 가중평균에 맞춰 색을 바꿀 수 있다. 종합 1~5등급 구간은 아직 확정하지 않았으며 코드에서 임의 생성하지 않는다. 표시 기준을 제목/범례에 명확히 적어야 한다.

현재 쾌적은 자치구 참고값이므로 치안·경제 등 다른 점수가 다르더라도 같은 구 동들의 쾌적 막대는 같다. 쾌적 내부 기온·미세먼지·소음 가중치는 영역 모델 담당자의 산출식이며 사용자 슬라이더와 별개다. 이번 작업에서 원래 모델 내부 가중치를 변경하지 않았다.
