# DB 연동 상태와 다음 단계

현재 모듈은 PostgreSQL에 연결하지 않습니다. 동봉된 ai_modeling/ 파일 스냅샷에서5대 점수·출처를 읽어 가중평균 추천과 설명을 제공합니다. 배포/업로드는 DB연동완료를 뜻하지 않습니다.

백엔드 전달 대상은 recommendation_service/ 전체입니다. 데이터만 필요한 경우 ai_modeling/ 아래 영역별 결과와검증파일을 함께 참고하세요. 실제DB접속키는패키지에없습니다.

DB연동을하려면 다음을확정해야합니다.

1. region_code6자리/sigungu_code5자리 마스터와 DB저장값의 일치.
2. 추천용 영역점수와 배포버전·원천기간·공간단위·추정/보정·승인상태의 저장위치.
3. 데이터엔지니어의 적재·검증·활성배포본 전환 정책.
4. 백엔드가 DB조회 결과를 SnapshotDataset 계약으로 구성하는 저장소 어댑터. 점수만읽고출처를버리지않음.
5. API에서슬라이더값을전달하고지역목록/선택/추천결과와연결하는통합테스트.

OpenRouter 키와 PostgreSQL의 호스트·DB명·계정·비밀번호는 서버 환경변수/비밀저장소로 주입합니다. 현재클라이언트는OpenRouter환경설정을읽는예제만있으며DATABASE_URL로자동연결하는코드는없습니다. 운영DB에DDL을자동실행하지않습니다.

원시자료테이블과모델산출점수테이블은다릅니다. 기존DB구축검토의파괴적DDL,에너지5자리FK문제,전체교체/이력정책등은DB담당자가별도로해결해야합니다. 이업로드는기존database/나backend/를수정하지않습니다.
